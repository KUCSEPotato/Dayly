# v0.1.0 · Personal Todo MVP

v0.2 작업 전 구현되어 있던 기능을 정리한 기록입니다. 다음 버전: [v0.2.0](v0.2.0.md). 서비스 소개와 기본 설치 방법: [README](../../README.md).

## Added

- 날짜별 Task 생성·조회·수정·삭제와 완료/미완료 전환, SQLite 영속 저장.
- 월간 달력, 날짜별 완료/전체 개수, 오늘 및 선택 날짜 표시.
- 선택 날짜 Progress Bar, 최근 7일 막대그래프, 전체 Task 수를 기준으로 한 주간 달성률.
- FastAPI Router, Pydantic Schema, SQLAlchemy Model, Service 계층과 Alembic `0001`.
- 입력 검증, 404 처리, 오류 및 재시도 화면, 모바일 레이아웃.

## Changed

- 최초 MVP로, 이전 정식 버전과의 변경 사항은 없습니다.

## Fixed

- 최초 MVP로, 이전 정식 버전에서 이월된 수정 내역은 없습니다.

## Development / Infrastructure

- pytest, 실제 API를 사용하는 Playwright 테스트와 TypeScript/Vite 빌드.
- Docker Compose의 Nginx + FastAPI 구성, 기본 로컬 포트 8080, SQLite named volume.
- 시작 시 Alembic 적용, 준비 상태 검사, DB 백업 방법.

## Known Limitations

- 로컬 단일 사용자용이며 인증과 다중 사용자 권한이 없습니다.
- 상세 조회·수정은 최근 7일과 미래 일정에 제공하며 오래된 기록은 달력 집계만 조회합니다.
- Task 변경 이력, 과거 상태 복원, 회고 및 경험치 시스템은 포함하지 않았습니다.
